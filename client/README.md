  <h1>Proyecto Universitario: FERRAMAX-FRONT</h1>
  <img src="https://d100mj7v0l85u5.cloudfront.net/s3fs-public/styles/webp/public/2023-04/funciones-del-jefe-de-compras-6.png.webp?itok=Xf-9nwHr">
  <h4>FERRAMAX es un pequeño proyecto semestral evaluado realizado por 3 personas, este proyecto en síntesis consta de 2 partes el front-end y el back-end, este repositorio de github es únicamente el front-end, el <a href="https://github.com/Toomyhz/Ferramax-api">back-end</a> está en un repositorio apartado únicamente para el mismo.</h4>
  <h4>EL proyecto trata de dar una pagina web a una empresa de productos de reparacion, en este se tiene que encontra:</h4>
  <ul>
    <li>Inicio de sesion</li>
    <li>Registro de usurio</li>
    <li>Carrito</li>
    <li>Productos con precio pesos chilenos/ dolares</li>
    <li>Suscribirse</li>
    <li>Transbank mas las respeuestas</li>
  </ul>
  <h4>AL ser un proyecto armado en 2 piezas es necesario el uso de tanto la api como la del front para que asi la pagina funcione optimamente, asi dando con todas las funciones implementadas del proyecto.</h4>
