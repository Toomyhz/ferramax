# Ferramax
  
E-commerce orientado a las necesidades básicas de una ferretería, sus principales características son:

- Backoffice para gestión de ferretería (en desarrollo)
- Autenticación de clientes para historial de compras
- Suscripción a "newslatter" comercial (en desarrollo)
- Integración con Banco Central para cambio de divisa a dolares
- Integración con Transbank para simulación de compras
  
## Tecnologías utilizadas:
- Python (3.12.10)
- Flask
- Vue3
- MySQL
